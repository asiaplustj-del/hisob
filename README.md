# Hisob.

Личный журнал расходов — PWA для iPhone. Быстрый ввод («3» → «вода» → ✓), умные подсказки и категории, журнал, отчёты с графиками, раздел «Люди», бэкап и импорт.

Все данные хранятся только на устройстве (IndexedDB). В репозитории — только код.

## Установка на iPhone
1. Открыть сайт в **Safari**.
2. «Поделиться» → «На экран „Домой“».
3. Запускать с иконки — работает без интернета.
